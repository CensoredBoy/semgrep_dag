## ❌ Критические проблемы

### 1. Правила с проверкой контекста PythonOperator (6 правил)

**Проблема:** Правила ищут функции, которые используются в `PythonOperator`, но Semgrep не может связать определение функции с её использованием в другом месте файла.

**Затронутые правила:**
- `airflow-eval-in-python-callable`
- `airflow-exec-in-python-callable`
- `airflow-pickle-loads`
- `airflow-marshal-loads`
- `airflow-os-system`
- `airflow-subprocess-shell-true`

**Решение:**
1. Упростить правила - искать опасные функции везде (как в strict версиях)
2. Или использовать `pattern-inside` для поиска внутри функций, которые могут быть использованы в PythonOperator

### 2. Правила для Jinja шаблонов (8 правил)

**Проблема:** Semgrep плохо работает с Jinja шаблонами внутри строковых литералов. Паттерны типа `"{{ dag_run.conf[...] }}"` не сопоставляются корректно.

**Затронутые правила:**
- `airflow-bash-unsafe-jinja-params`
- `airflow-bash-unsafe-jinja-xcom`
- `airflow-ssh-unsafe-command`
- `airflow-k8s-unsafe-image`
- `airflow-k8s-unsafe-env`
- `airflow-k8s-unsafe-volumes`
- `airflow-docker-unsafe-image`
- `airflow-bash-jinja-whitelist`

**Решение:**
Использовать `metavariable-regex` для поиска шаблонов в строках (как в `airflow-bash-unsafe-jinja-conf`).

### 3. Правила для SQL Injection (8 правил)

**Проблема:** Паттерны не покрывают все варианты использования операторов и формирования SQL.

**Затронутые правила:**
- `airflow-sql-concat-fstring`
- `airflow-sql-concat-plus`
- `airflow-sql-concat-format`
- `airflow-sql-from-conf`
- `airflow-sql-from-xcom`
- `airflow-sql-any-concat`
- `airflow-sql-from-variable`
- `airflow-sql-from-env`

**Решение:**
1. Расширить паттерны для разных вариантов операторов
2. Использовать более гибкие паттерны для поиска конкатенации

### 4. Правила для K8s/Docker (7 правил)

**Проблема:** Аналогично Jinja шаблонам - сложно искать динамические значения в параметрах операторов.

**Затронутые правила:**
- `airflow-k8s-unsafe-security-context`
- `airflow-k8s-unsafe-service-account`
- `airflow-k8s-unsafe-volume-mounts`
- `airflow-k8s-unsafe-namespace`
- И другие из airflow-k8s-operator.yml

**Решение:**
Использовать `metavariable-regex` для поиска Jinja шаблонов в параметрах.
