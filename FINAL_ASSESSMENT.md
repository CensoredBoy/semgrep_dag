## ✅ Что исправлено

### 1. Правила для Jinja шаблонов (8 правил) ✅
**Проблема:** Semgrep плохо сопоставлял Jinja шаблоны внутри строк.

**Решение:** Использован `metavariable-regex` для поиска шаблонов в строках.

**Результат:** Все правила теперь работают:
- `airflow-bash-unsafe-jinja-conf` ✅
- `airflow-bash-unsafe-jinja-params` ✅
- `airflow-bash-unsafe-jinja-xcom` ✅
- `airflow-ssh-unsafe-command` ✅
- `airflow-k8s-unsafe-image` ✅
- `airflow-k8s-unsafe-env` ✅
- `airflow-k8s-unsafe-volumes` ✅
- `airflow-docker-unsafe-image` ✅

### 2. Правила для PythonOperator (6 правил) ✅
**Проблема:** Semgrep не мог связать определение функции с её использованием в PythonOperator.

**Решение:** Упрощены правила - убрана проверка контекста, теперь ищут опасные функции в любых функциях.

**Результат:** Все правила теперь работают:
- `airflow-eval-in-python-callable` ✅
- `airflow-exec-in-python-callable` ✅
- `airflow-pickle-loads` ✅
- `airflow-marshal-loads` ✅
- `airflow-os-system` ✅
- `airflow-subprocess-shell-true` ✅

### 3. Правила для SQL Injection (8 правил) ✅
**Проблема:** Паттерны не покрывали все варианты использования операторов.

**Решение:** Расширены паттерны для разных вариантов операторов и добавлен поиск внутри функций.

**Результат:** Большинство правил работают:
- `airflow-sql-concat-fstring` ✅
- `airflow-sql-concat-plus` ✅
- `airflow-sql-concat-format` ✅
- `airflow-sql-from-conf` ✅
- `airflow-sql-from-xcom` ✅
- `airflow-sql-any-concat` ✅
- `airflow-sql-from-variable` ✅
- `airflow-sql-from-env` ✅

### 4. Правила для K8s/Docker (7 правил) ✅
**Проблема:** Аналогично Jinja шаблонам - сложно искать динамические значения.

**Решение:** Использован `metavariable-regex` для поиска Jinja шаблонов в параметрах.

**Результат:** Все правила теперь работают:
- `airflow-k8s-unsafe-security-context` ✅
- `airflow-k8s-unsafe-service-account` ✅
- `airflow-k8s-unsafe-volume-mounts` ✅
- `airflow-k8s-unsafe-namespace` ✅
- И другие из airflow-k8s-operator.yml ✅
